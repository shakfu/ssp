# Changelog

glitch follows [semantic versioning](https://semver.org). Until 1.0.0, a minor version may change parameters, so presets saved with an earlier version can restore differently.

The version is set in `CMakeLists.txt` (`project(GLITCH VERSION ...)`) and shown at the top right of the screen.

## 0.1.1 - 2026-10-08

A long Up or Down jumps between decks, a long Right (Prog +) to the mix page and a long Left back.

## 0.1.0 - 2026-10-08

First release, as the module `gltc`. Two decks, each running one of 12 Noisferatu algorithms, with two algorithm parameters, pitch, tone and level, and CV for pitch (V/oct) and both parameters. A/B crossfade, three stereo routes, and an output per deck. GPLv3. See [README.md](README.md).
